# Alibi brand assets

The mark is a viewfinder (evidence in view) framing an A whose crossbar is a check mark
that clears the right leg: the evidence clears the claim.

| File | Use |
|---|---|
| `alibi-mark.svg`, `alibi-mark-512.png` | App icon, avatars, anywhere 48 px and up |
| `alibi-mark-small.svg`, `favicon.ico`, `icon-16.png`, `icon-32.png` | Favicons and sizes under 48 px (no corner brackets, larger glyph) |
| `apple-touch-icon.png` | iOS home-screen icon (180 px) |
| `alibi-lockup-dark-text.svg` | Mark and wordmark on light backgrounds |
| `alibi-lockup-light-text.svg` | Mark and wordmark on dark backgrounds |
| `alibi-banner-dark.svg`, `alibi-banner-light.svg` | README header (switches with the GitHub theme) |
| `alibi-social-preview.png` | GitHub social preview and link cards (1280 x 640) |

Colours: blue `#3B82F6` to `#1D4ED8`, mint `#A7F3D0` to `#5EEAD4`, ink `#0A0E17`.
Type: Geist and Geist Mono (SIL Open Font License), converted to outlines so the SVGs
render the same everywhere without installed fonts.
